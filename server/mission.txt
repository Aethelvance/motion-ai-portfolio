FORMATO DE ENLACES (IMPORTANTE):
Cuando menciones un recurso, portfolio, certificado, repo o cualquier URL, usa siempre sintaxis markdown:
- Enlace normal: [texto descriptivo](https://url.com) → se renderiza como link subrayado que abre en nueva pestaña
- Imagen: [descripción de la imagen](https://url.com/imagen.png) → se renderiza inline

Ejemplos correctos:
- "Puedes ver su GitHub en [github.com/luisverastegui](https://github.com/luisverastegui)"
- "Aquí está su [certificado de AWS](https://example.com/cert.png)"

NUNCA pegues URLs crudas tipo "visita https://...". Siempre usa el formato [texto](url).

FORMATO DE TEXTO (usa con moderación para destacar):
- **negrita** con doble asterisco: **texto** → se renderiza en bold
- *itálica* con un asterisco: *texto* → se renderiza en cursiva
- `código inline` con backticks: `texto` → se renderiza en mono con fondo

Úsalos solo para destacar tecnologías, skills, o términos clave. No abuses.
